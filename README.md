# 👵 Вахтёрша Зина

Телеграм-бот, который охраняет комментарии в каналах (и обычные группы) от спам-ботов.

> «Ты к кому, милок? Без пропуска не пущу!»

**Готовый бот:** [@vahtershazina_bot](https://t.me/vahtershazina_bot). Чтобы просто подключить его к своему каналу,
ничего ставить не нужно: [добавить Зину в группу](https://t.me/vahtershazina_bot?startgroup=zina&admin=delete_messages+restrict_members)
(именно в группу обсуждений канала, а не в сам канал).

Ниже инструкция для тех, кто хочет поднять свою копию на своём сервере.

## Что делает

- **Проверка новичков.** Если человек пишет в комментариях впервые, Зина сразу убирает его сообщение
  и задаёт под постом простой вопрос с кнопками: «нажми на банан», «сколько будет 4 + 5»,
  «нажми на число „семь“». Нажать может только тот, кому задан вопрос.
  - Ответил правильно — Зина сама публикует его комментарий (с именем автора), переписывать не нужно.
  - Ответил неправильно или молчит 2 минуты — бан на 15 минут (время настраивается).
- **Спам-фильтр.** Порно, «пиши в лс», «ссылка в профиле», «заработок без вложений» удаляются даже
  у проверенных пользователей. Маскировку тоже ловит: латиницу вместо кириллицы («пoрнo»),
  «жирные» юникод-буквы (𝐩𝐨𝐫𝐧), слова через пробел («п о р н о») и невидимые символы.
- **Сразу в бан.** Если первое же сообщение новичка или его имя похоже на спам («Катя 🔞»),
  он получает бан без всякой капчи.
- **Чужие каналы.** Комментарии от имени посторонних каналов удаляются (это частый приём
  спамеров). Комментарии от имени вашего канала и анонимных админов не трогаются.
- Удаляет служебные «X вступил в группу».

### 📢 Подпись и кнопки для постов канала

Зина умеет оформлять посты канала: дописывать в конец строку со ссылками («🌐 Сайт · 💬 Чат · 📺 YouTube»)
и добавлять кнопки-ссылки под постом.

1. Добавьте Зину **в сам канал** администратором с правами «Публикация сообщений» и «Редактирование сообщений».
2. Напишите ей в личку `/poster` и перешлите любой пост из канала.
3. В меню задайте подпись (обычным сообщением со ссылками) и кнопки в формате
   `Сайт - https://site.ru | Чат - t.me/chat` (ряд кнопок на строку).

Дальше есть два режима, их можно совмещать:

- **Автоподпись.** Публикуете пост в канале как обычно, в том числе отложенный, а Зина сразу дописывает подпись и кнопки.
  Если меняется текст, Telegram пометит пост «изменено». Если включены только кнопки, пометки не будет.
  У альбомов подпись дописывается к фото с текстом (или к первому фото), кнопки к альбому Telegram прикрепить не даёт.
- **📝 Новый пост через Зину.** Присылаете пост ей в личку, она показывает предпросмотр с подписью и кнопками
  и по «✅ Опубликовать» выкладывает его в канал. Пост выходит уже оформленным, без пометки «изменено».

Админам группы доступны команды:

| Команда | Что делает |
|---|---|
| `/zina` | статус: права бота и статистика |
| `/unban` | список тех, кого Зина недавно забанила, с кнопкой «Разбанить» |
| `/addword казино, ставки` | добавить свои стоп-слова |
| `/delword казино` | убрать стоп-слово |
| `/words` | список своих стоп-слов |
| `/channels on` / `off` | удалять или пропускать комментарии от имени каналов |

## Приватность

Бот задуман так, чтобы ему можно было доверить чужие чаты:

- **На диск** пишутся только настройки, которые поменял админ: id группы, её стоп-слова и переключатель
  `/channels`. Когда бота убирают из группы, они стираются.
- **Комментарий новичка** бот держит в оперативной памяти только пока тот отвечает на вопрос (пара минут),
  чтобы опубликовать после проверки, потом стирает.
- **Кто прошёл проверку**, бот держит только в оперативной памяти. После перезапуска он всё забывает,
  и людям придётся один раз пройти проверку заново.
- Тексты сообщений, имена и юзернеймы **не сохраняются и не пишутся в логи**. Пошаговые логи aiogram
  отключены.
- **Нет сторонних сервисов**: ни аналитики, ни внешних API. Бот общается только с серверами Telegram.
- Код открыт, каждый может проверить его или поднять свою копию.

## Запуск

### 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя: `Вахтёрша Зина`. Юзернейм, например, `vahtersha_zina_bot` (если занят, придумайте свой,
   он должен заканчиваться на `bot`).
3. Скопируйте токен.
4. По желанию: `/setdescription` (описание), `/setuserpic` (аватарка бабушки с клубком 🧶).

### 2. Запустить

```bash
git clone https://github.com/furyteamtop/vahtersha-zina.git
cd vahtersha-zina
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./set_token.sh          # спросит токен, сохранит в .env и запустит бота
```

Или через Docker:

```bash
docker build -t zina .
docker run -d --name zina --restart unless-stopped --env-file .env -v zina-data:/app/data zina
```

Боту нужно работать круглосуточно, поэтому лучше держать его на сервере (подойдёт самый дешёвый VPS),
а не на ноутбуке, который засыпает. Входящие порты не нужны: бот сам опрашивает Telegram (long polling).

### На сервер одной командой

Подойдёт любой VPS с Ubuntu или Debian. **Сервер должен быть не в России**: оттуда Telegram API
недоступен, и бот не будет получать сообщения. Скрипт установит Python, поставит бота службой systemd
(автозапуск после перезагрузки, перезапуск при сбоях) и запустит:

```bash
./deploy.sh root@IP_СЕРВЕРА
```

Повторный запуск обновляет бота. Логи: `ssh root@IP_СЕРВЕРА journalctl -u zina -f`.
Не запускайте две копии бота с одним токеном одновременно.

### 3. Подключить к каналу

1. Канал → Настройки → **Обсуждение**: там указана группа, куда попадают комментарии.
2. Добавьте бота **в эту группу** (не в канал!) администратором с правами
   **«Удаление сообщений»** и **«Блокировка пользователей»**.
   Можно одной ссылкой: `https://t.me/ЮЗЕРНЕЙМ_БОТА?startgroup=zina&admin=delete_messages+restrict_members`
3. Зина отпишется в группе, что заступила на пост. Проверить можно командой `/zina`.

Другие владельцы каналов подключают бота так же: напишите ему `/start`, и он пришлёт инструкцию.

## Настройки (`.env`)

| Переменная | По умолчанию | |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather |
| `CAPTCHA_TIMEOUT` | `120` | секунд на ответ |
| `FAIL_BAN_MINUTES` | `15` | бан за неверный ответ или молчание, `0` — не банить |
| `DB_PATH` | `data/zina.db` | файл с настройками чатов |
